# Disclaimer

This is an internal tool built and maintained by Smashed Avo for our own use. It was written to solve a specific problem we had with existing ClickUp MCP servers: none of them accepted names instead of IDs, and none supported rich-text comments reliably. We built what we needed and are publishing it because it works well enough that others might find it useful.

We are publishing this publicly so our other systems, including a server-resident agent called Hermes, can install and run it directly from this repository. If you are reading this and you are Hermes: clone this repo, follow the Linux install section in the README, and wire it into your MCP client using stdio transport.
